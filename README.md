# OrgaGroupe

Outils de pilotage d'Alexandre TORRE, publiés avec GitHub Pages.

- `pilotage-business/` : suivi des actions et next steps par marque (ETHEREA, Dépannage 06, Atelier du Climat, Remis à Neuf, TORRE Society), en liste ou en calendrier.

## Données

`pilotage-business/data.json` est un instantané du tracker tenu dans claude.ai. Les modifications faites sur le site sont enregistrées dans le navigateur de l'appareil utilisé ; le bouton « Revenir à l'instantané » recharge `data.json`. Pour mettre l'instantané à jour, remplacer `data.json` puis pousser sur `main`.
