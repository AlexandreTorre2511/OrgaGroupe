# Dossier commercial syndics ETHEREA et Dépannage 06

Site du dossier commercial destiné à la commerciale terrain : offres, références, argumentaire, objections, plan d'action jusqu'au 31 décembre 2026 et suivi des pistes.

## Mettre à jour le site

1. Modifier `dossier.md` (contenu) ou `template.html` (mise en page).
2. Lancer `python3 build.py` pour régénérer `index.html` (nécessite `pip install markdown`).
3. Commit et push sur `main` : GitHub Pages republie automatiquement.
